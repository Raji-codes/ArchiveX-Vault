ABSTRACT

In modern enterprise environments, organizations generate vast quantities of semi-structured and unstructured documents—including invoices, legal contracts, travel receipts, lab panels, and operational records. Traditional document storage relies on static folder hierarchies and rudimentary filename searches, creating data silos where vital business intelligence remains trapped in non-searchable PDFs and scanned raster images.

This project, "ARCHIVEX: Cloud Content Discovery System and Intelligent Document Vault with OCR Indexing," aims to solve enterprise content retrieval bottlenecks through an end-to-end cloud pipeline. Built upon React 19, TypeScript, Express, and modern web APIs, ArchiveX accepts documents through a modern drag-and-drop ingestion portal, runs asynchronous optical character recognition (OCR), extracts key entities (monetary amounts, dates, vendor names), and auto-assigns taxonomy tags (e.g., #invoice, #financial, #tax, #contract).

The discovery subsystem offers sub-millisecond search capability with keyword highlighting, multi-tag intersection filters, dual dense-table and visual card presentations, and Amazon Web Services (AWS) S3 storage synchronization. Experimental evaluations demonstrate sub-second indexing times for multi-page documents and substantial discovery speed improvements compared to conventional file systems.

The project demonstrates how full-stack cloud engineering and intelligent parsing can be combined to deliver high-performance, clutter-free enterprise document vaults.

1. INTRODUCTION

1.1 Overview of Document Archiving & Content Discovery

In modern digital enterprises, documentation represents the operational backbone of business activity. Across accounting, legal, human resources, logistics, and engineering departments, organizations process thousands of documents weekly. These assets arrive in disparate formats—scanned image files (.png, .jpeg, .tiff), portable document format files (.pdf), text files (.txt), and structured metadata (.json). Content Discovery refers to the capability of corporate search engines to accurately locate, retrieve, and interpret information locked inside these document repositories.

1.2 Need for Intelligent Vault & OCR Indexing

Traditional storage architectures index files solely by filename and folder path. If an invoice filename is saved arbitrarily as Scan_00491.pdf, its monetary amount ($4,451.60), vendor name (Stripe Payments Inc.), and line items remain completely invisible to search queries. An Intelligent Vault bridges this gap by automatically extracting text, identifying semantic entities, and creating indexed tokens upon file ingestion.

1.3 Existing System

In existing corporate environments, document management relies on basic network file shares or generic cloud folders. Employees must manually open each document, inspect its content, classify it into appropriate folder trees, and manually input invoice numbers into spreadsheets.

Limitations of Existing System:

  • Manual analysis requires significant administrative time and effort.
  • Inability to search within scanned raster images and non-vector PDFs.
  • High risk of document misplacement and indexing inconsistency.
  • Lack of real-time metadata indexing and automated entity detection.
  • Slow response times during compliance audits and financial reviews.

1.4 Proposed System

The proposed system, ArchiveX, is an intelligent Cloud Content Discovery System and Document Vault. It replaces slow, error-prone manual archiving with an automated, browser-accessible, full-stack pipeline. It extracts text asynchronously, detects monetary amounts and vendor counterparties, generates smart hashtags, and supports live search with keyword highlighting.

14. CONCLUSION AND FUTURE ENHANCEMENTS

The ArchiveX project successfully implements an end-to-end Cloud Content Discovery System and Intelligent Document Vault. By bridging optical character recognition with high-speed indexing and cloud storage, ArchiveX eliminates the traditional overhead of manual filing. The system delivers instant drag-and-drop ingestion, automated taxonomy tag assignment, deep full-text discovery with highlighted matching, and seamless AWS S3 synchronization.

Future Enhancements:

  • Integration of LLM-based Retrieval-Augmented Generation (RAG) for conversational queries over documents.
  • Multi-tenant Role-Based Access Control (RBAC) with granular security permissions.
  • Serverless event-driven AWS Lambda workers triggered directly by S3 ObjectCreated events.
  • Multi-language OCR support covering international character sets.
